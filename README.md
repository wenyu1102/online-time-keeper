# 在线时长助手（Online Time Keeper）

> 京麦（咚咚）客服在线时长统计小工具 · 一个 Windows 桌面应用

## 为什么做这个工具

电商客服每天有 **最低在线时长要求（默认 7 小时 30 分）**，班次内有富余时间可以去吃饭、休息、上厕所。
但如果不记录离线时间，到了下班点常常不知道：

- 今天在线时长够不够？
- 还差多少？需要加班补多久、补到几点？

这个工具就是为解决这个问题而生的：**一键记录在线/离线，实时显示达标进度和补时长建议**，避免补多或补少。

## 功能特性

- **一键记在线/离线**：离开工位点一下（或按全局热键 `Ctrl+Alt+O`），回来再点一下，自动累计当天在线时长
- **实时达标进度**：主界面显示今日在线时长、「还差 XX:XX:XX」、预计达标时间
- **三个班次预设**：早班 08:30-17:00 / 中班 11:00-20:00 / 晚班 14:00-22:00，可自定义时间与目标时长
- **下班自动判断**：到下班点还差时长时，通知「还差 XX，预计需在线至 HH:MM 才达标」，不再凭感觉补时长
- **锁屏自动记离线**：锁屏自动记为离线，解锁自动回到在线（可关闭）
- **托盘常驻**：关闭主窗口后程序在系统托盘继续计时，悬停托盘图标即可看到当前在线时长
- **悬浮小窗**：屏幕角落常驻显示在线时长，不占用聊天窗口视线
- **历史记录**：每天自动存档（日期/班次/在线时长/是否达标），支持补记与修正误操作

## 快速开始

### 下载

从 [Releases](https://github.com/wenyu1102/online-time-keeper/releases) 下载 `OnlineTimeKeeper-v1.0.0.exe`（单文件，免安装，双击即用）。

> 首次运行如遇 SmartScreen 提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可（未签名的个人开源程序）。

### 使用

1. 上班开始接待前启动程序，确认按钮为绿色「开始离线（去吃饭/休息/上厕所）」= 正在计时
2. 离开工位：点按钮或按 `Ctrl+Alt+O` → 变为「回到在线（继续接待）」
3. 回到工位：再点一下（或按热键）
4. 下班前看一眼：右下角「下班时预计」绿色 = 能达标；红色 = 还差时长，提示条会告诉你要补到几点

### 忘记点按钮？

主窗口 →「今日记录」：可补记一段在线时段、结束最后一段（到现在）、删除记错的时段。

## 数据存储

数据保存在 exe 同目录的 `data` 文件夹：

- `config.json` — 配置（班次、目标时长、热键等）
- `daily.json` — 每天的在线上时段记录
- `app.log` — 运行日志

备份 `daily.json` 即可带走全部考勤数据。

## 从源码构建

需要 Python 3.10+ 和能联网的环境：

```powershell
# 安装依赖
pip install -r requirements.txt

# 运行（开发模式）
python main.py

# 核心逻辑自测（无界面）
python main.py --selftest

# 一键打包 exe
powershell -ExecutionPolicy Bypass -File build.ps1
# 产物：dist\在线时长助手.exe
```

`build.ps1` 会：安装依赖 → 生成图标 → 用 PyInstaller 打包单文件 exe。
